# Introducción: Tarea antes de aplicación

Si la tarea es especializada, defínela antes de exponer aplicaciones. Si ya es conocida, puedes omitir la definición.

«La tarea de {nombre} busca recuperar/reconstruir/estimar {salida} a partir de {entrada}».
«Tiene aplicaciones en {casos representativos}».

Ejemplo: la estimación de pose obtiene orientación y traslación de un objeto respecto a un sistema canónico desde una imagen. Es importante para realidad aumentada, conducción autónoma y manipulación robótica.
