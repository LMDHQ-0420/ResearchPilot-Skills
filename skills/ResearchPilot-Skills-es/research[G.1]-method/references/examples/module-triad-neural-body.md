# Tres elementos de un módulo: Neural Body

Usa Neural Body para distinguir diseño, motivación y ventaja técnica.
- Diseño: representación/red y proceso de ejecución.
- Motivación: desafío pendiente que exige el módulo.
- Ventaja: por qué mejora frente a alternativas.

Lee [Ejemplo anotado](example-of-the-three-elements.md), identifica el papel de cada párrafo y organiza tu subsección con los mismos elementos y el orden confirmado. Este archivo sustituye referencias de las notas originales a figuras anotadas no incluidas.
