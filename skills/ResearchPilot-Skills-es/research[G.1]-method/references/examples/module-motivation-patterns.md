# Patrones para motivar un módulo

La motivación parte de un problema: porque existe X, diseñamos Y para resolverlo.
Aperturas posibles:
1. «Un problema pendiente es …».
2. «Sin embargo, …».
3. «Los métodos anteriores tienen dificultades para …».

Expón el fallo concreto antes del módulo y distingue la motivación de sus detalles de implementación.
