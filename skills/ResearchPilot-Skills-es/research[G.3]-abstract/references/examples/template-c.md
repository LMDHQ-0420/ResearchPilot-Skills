# Plantilla C: Varias aportaciones

Cada frase técnica vincula aportación y ventaja.

## Ejemplo adaptado de Deep Snake

Se introduce Deep Snake para segmentación de instancias en tiempo real basada en contornos.
Frente a la regresión directa de coordenadas del borde, una red deforma iterativamente un contorno inicial hasta el límite del objeto, realizando mediante aprendizaje la idea de contornos activos.
Para aprender características estructuradas, la convolución circular aprovecha la estructura de ciclo mejor que una convolución de grafo genérica.
El procedimiento de propuesta inicial y deformación posterior permite corregir errores de localización.
Concluye con resultados reales.
