# Plantilla A: Desafío → aportación

```latex
\section{Resumen}
% Tarea.
% Desafío técnico de los métodos anteriores, centrado en el que resolvemos.
% Aportación técnica en una o dos frases: nombre claro, sin detallar todos los pasos.
% Ventajas.
% Resultados experimentales reales.
```

Esqueleto:
1. {Tarea}.
2. Los métodos anteriores presentan {desafío técnico}.
3. Para resolverlo proponemos {nombre de la aportación}.
4. {Segunda frase de aportación, si hace falta}.
5. Esto permite {ventaja}.
6. Los experimentos muestran {cifras reales}.
